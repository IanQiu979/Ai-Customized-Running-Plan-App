# Workout Library — Running Sessions Only

Ported subset of `workout_library.md` Part 1 (all 9 running session types). Part 2
(cross-training equivalences) is not ported — plans are running-only (Ian's decision, see
`00-README.md`). Every session type's "Fuel" sub-section is also dropped — nutrition/fueling
content is out of scope for a plan generator. Cadence cues are qualitative only; see
`training-zones.md` § Cadence for why the source's absolute SPM numbers don't survive the port.

## Session 1: Easy Run (Zone 1)

*(workout_library.md § Session Type 1)*

| | |
|---|---|
| Purpose | Aerobic base building, economy development, active recovery |
| Duration | 30–60 minutes |
| Frequency | 4–5×/week — the majority of all training |
| Target HR | 60–70% max HR |
| RPE | 2–4 / 10 |

**Structure:** 5 min very easy warm-up → main run at consistent Zone 1 effort → 5 min easy
cool-down. Optional 4–6 × 20 sec strides at the end (beginner/intermediate only).

**Cues:** keep HR truly low — "if you feel like you could go faster, you're at the right pace."
Light, quick, relaxed steps ("quick, light feet"), no forcing a number. Relaxed shoulders, arms at
roughly 90 degrees — this is the best run to practice form on, since there's no fatigue in the
way. Resist the urge to race; patience here builds the base that makes hard runs possible.

**Common mistake to flag:** an "easy" run whose effort is really Zone 2 — the #1 error in
recreational runners, accumulating fatigue without the recovery benefit.

## Session 2: Recovery Run (Zone 1 — very easy)

*(workout_library.md § Session Type 2)*

| | |
|---|---|
| Purpose | Active recovery, blood flow, psychological maintenance |
| Duration | 20–30 minutes |
| Frequency | Day after hard sessions |
| Target HR | 55–65% max HR (low end of Zone 1) |
| RPE | 1–3 / 10 |

**Structure:** pure easy running, no structure required; stop if soreness is above 3/10; walk
breaks are fine.

**Cues:** zero pace focus, just move the body; let cadence be light and natural, don't force it.
Should feel embarrassingly easy — if the runner feels like they're wasting time, that's correct.

## Session 3: Tempo Run (Zone 2–3, sustained)

*(workout_library.md § Session Type 3)*

| | |
|---|---|
| Purpose | Lactate threshold development, race-pace conditioning |
| Duration | 35–55 minutes total, including warm-up/cool-down |
| Frequency | 1×/week |
| Target HR | 75–85% max HR |
| RPE | 6–7 / 10 |

**Structure:** 10 min easy warm-up → 20–30 min sustained tempo effort → 5–10 min easy cool-down.
Run it **at or slightly below** lactate threshold, not right at it — allows more volume without
burnout and produces better long-term adaptation.

**Pace guidance:** beginner, 30–45 sec/km faster than easy pace; intermediate, 45–60 sec/km
faster; advanced, race-specific threshold pace.

**Cues:** controlled, not desperate — "sustainable for 30 minutes" is the test of the right
effort. Cadence should feel steady even as legs fatigue; a felt cadence drop signals easing back
slightly. Posture stays tall through the effort.

## Session 4: VO2 Max Intervals (Zone 3–4)

*(workout_library.md § Session Type 4)*

| | |
|---|---|
| Purpose | VO2 max development, speed endurance |
| Duration | 45–65 minutes total |
| Frequency | 1×/week maximum |
| Target HR | 85–95% max HR during intervals |
| RPE | 8–9 / 10 during intervals |

**Structure:** 15 min easy warm-up → 5–6 × 3–4 min hard, 90–120 sec easy jog recovery between →
5–10 min easy cool-down. Advanced variants: 4×5min/2min recovery, 6×3min/90sec, or 8×2min/60sec.

**Key coaching rule:** the first and last interval should be within 5–8 sec/km of each other; a
drop of more than 10 sec/km on the last interval means the pace was too aggressive — adjust the
next session.

**Cues:** hard but consistent, not "blowing up interval 1 and dying in interval 6" — that
consistency, not raw speed, is what the session is training.

## Session 5: Long Run (Zone 1, optional finish build)

*(workout_library.md § Session Type 5)*

| | |
|---|---|
| Purpose | Aerobic endurance, fat oxidation, mental toughness |
| Duration | 60–140 minutes, level-dependent |
| Frequency | 1×/week |
| Target HR | 60–70% max HR (Zone 1), can build to Zone 2 in the final 15–20% |
| RPE | 3–5/10 building to 5–6 at the finish |

**Duration by level:** beginner 45–75 min; intermediate 75–110 min; advanced 90–140 min (marathon:
up to 150 min).

**Caps:** see `load-rules.md` for the long-run percentage cap by level, the new long-run spike
cap, and the new long-run time cap — all enforced against this session type specifically.

**Structure:** start at very easy Zone 1 pace, hold it through the middle; optional final 10–20%
builds to Zone 2 (negative-split practice); walk breaks acceptable for beginners.

**Cues:** the long aerobic investment — start easy, the adaptation happens by staying in Zone 1
for duration. Even effort throughout; a felt cadence drop in the final stretch signals
fatigue-based form breakdown, worth a mid-run posture reset. Negative-split strategy: save energy
early, push the finish.

## Session 6: Fartlek Run (unstructured intervals)

*(workout_library.md § Session Type 6)*

| | |
|---|---|
| Purpose | Mental freshness, aerobic and speed development, variety |
| Duration | 40–55 minutes |
| Frequency | 1×/week, alternative to structured intervals |
| Target HR | Mix of Zone 1–2 (easy) and Zone 3 (hard) |
| RPE | 3–7/10, varies |

**Structure:** 10 min easy warm-up → 20–25 min main set alternating 2–3 min hard (Zone 3) with
1–2 min easy (Zone 1), 4–5 cycles → 5 min easy cool-down. Removes the pressure of hitting exact
pace targets while still building fitness — good for runners who dislike structured intervals.

## Session 7: Threshold / Cruise Intervals

*(workout_library.md § Session Type 7)*

| | |
|---|---|
| Purpose | Lactate threshold building via repeated sustained hard effort |
| Duration | 50–70 minutes total |
| Frequency | 1×/week, alternative to tempo runs |
| Target HR | 80–90% max HR |
| RPE | 7–8/10 |

**Structure:** 15 min easy warm-up → 3–4 × 2–3 km at Zone 2–3 effort, 1–2 min easy recovery
between → 10 min easy cool-down. Differs from tempo by breaking the same threshold stimulus into
multiple repeats with brief recovery, allowing more volume at hard effort than one continuous
block.

**Cues:** each repeat should hold pace within 5 sec/km of the others — consistency is the test.

## Session 8: Hill Repeats (power / strength)

*(workout_library.md § Session Type 8)*

| | |
|---|---|
| Purpose | Leg strength, power development, running economy |
| Duration | 40–55 minutes total |
| Frequency | 1–2×/week, substitute for flat intervals |
| Grade | 3–5% gradient, sustained |
| Repeats | 6–8 × 3–4 min hard uphill, jog/walk down recovery |

**Structure:** 10 min easy warm-up → 6–8 × 3 min hard uphill (Zone 3–4) → 10 min easy cool-down.
Hills naturally shorten stride and increase cadence without a forced number, and are considered
safer than flat interval work for injury prevention.

**Cues:** push hard uphill; keep the recovery jog down easy and long to protect the knees.

## Session 9: Strides (neuromuscular activation)

*(workout_library.md § Session Type 9)*

| | |
|---|---|
| Purpose | Speed, power, neuromuscular activation, stride mechanics |
| Duration | 20–30 sec × 4–6 reps |
| Frequency | 2–3×/week, end of easy runs |
| Target HR | 95–100% max HR |
| RPE | 9–10/10 |

**Structure:** after an easy run, 4–6 strides — 20–30 sec gradual build from easy to near-max
speed (never a flying start), full recovery jog (90 sec minimum) between each.

**When to use:** end of easy runs (2–3×/week); the day before a hard session (1×/week); during
deload weeks, to maintain the feel for speed without adding fatigue. Never after hard sessions.
